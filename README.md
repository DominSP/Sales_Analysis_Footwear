# Sales Analysis for a Footwear Store

## Overview

This project presents a sales analysis for a footwear store using
spreadsheet-based data analysis.

## Contents

-   `Analiza_Excel.xlsx` --- Excel version of the analysis.
-   `Analiza_Excel.ods` --- OpenDocument Spreadsheet version.

## Tools

-   Microsoft Excel / spreadsheet analysis
-   Data analysis
-   Data visualization

## Project Focus

The project demonstrates the use of spreadsheet tools to organize,
analyze and present business data related to footwear sales.

## Purpose

The goal of the project is to turn sales data into useful information
that can support business analysis and decision-making.
